# 0.11.1 candidate — Windows app window

On Windows, JNSQ opens in a resizable Chromium app window with minimize,
maximize/restore and close controls. Closing the owned window stops the session;
refreshing it and switching panes keep the household running. Firefox remains
the fallback. JNSQ.bat is a short launcher for the same lifecycle.

This candidate starts from the exact v0.11.0 public distribution. It adds only
the window/launcher change. Household 3D, Travel Window, OmniVoice, document
changes and new autonomy systems are not included.
