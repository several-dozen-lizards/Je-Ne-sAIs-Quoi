Download JNAIQ Builders

About 666 MB download. Install Python 3.10+, extract the helper into a new folder, run DOWNLOAD_BUILDERS.bat, then INSTALL_BUILDERS.bat and START_BUILDERS.bat. Connect above using its port. World Builder includes opt-in experimental VR viewing: clunky, incomplete, and not tested on real headsets. Editing stays on the desktop.

Builders is a separate installation with its own saved designs and worlds. Its asset packs are not part of the main JNAIQ download.

Prepared models work without a Godot editor or a model API key. Additional hair and clothing fitting needs separate Blender/MPFB tools. See the release's asset notices before redistributing models.

Saved work belongs to the Builders installation. Back up that entire folder, including imported assets. Opening an editor does not assign an avatar to a resident or publish a world into the household.
